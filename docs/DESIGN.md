# 설계 결정 및 로드맵

## 기본 방침

- GitHub Pages 정적 호스팅이므로 해석 전체를 브라우저(TypeScript, Web Worker)에서 수행
- 내부 좌표계 Z-up, 단위 mm / N / tonne / s
- 입력은 Rhino/Grasshopper에서 내보낸 JSON이 주력, OBJ(선 요소)는 간이 입력
- 정밀 검증은 Abaqus `.inp` 내보내기로 로컬 교차검증 (정합성 목표 약 80%)

## 요소

- 바: 3D 보요소 6자유도, 단부 릴리스(핀/강접합), 이후 회전 스프링 확장
- 쉘: 삼각형(MITC3 계열) 우선, 사각형은 삼각형 2개로 분할, 두께는 입력값
- 집중질량: 절점 질량 및 회전관성
- 힌지: 패널 ID 쌍, 웹 UI에서 엣지 매칭 후 유형 지정 (강접 / 자유 / 회전스프링 / 비연결)

## 바 요소 규약

- 국부 x는 절점 i에서 j 방향, `orient`는 국부 z 방향의 참조 벡터 (미지정 시 전역 Z, 수직 부재는 전역 X)
- Iy는 국부 y축 둘레 휨 (국부 x-z 평면 휨), Iz는 국부 z축 둘레 휨 (국부 x-y 평면 휨)
- 단부 릴리스 `[[rx,ry,rz],[rx,ry,rz]]`: 1이면 해당 회전 해제, 정적응축 (질량은 Guyan 축소)
- 강성/질량이 전혀 없는 자유도(핀만 연결된 절점의 회전 등)는 자동 제외하고 안내
- 질량은 일관질량행렬 + 절점 집중질량, 자중은 재료 밀도로 자동 반영

## 해석

- 고유치: Free-free 및 구속 모달, 강체모드와 기구모드 구분 표시
- 응답: 모드중첩법과 Newmark-β 직접적분, 베이스 가진 (CSV: t, ax, ay, az)
- 감쇠: 모드별 감쇠비 기본, Rayleigh 선택
- 자유도 분석: 강체 자유도(구속 야코비안 영공간)와 유연 자유도(강성행렬 저에너지 모드) 별도 모듈

## 오리가미 대응

- 접힘 기구학: 강체 오리가미 우선, bar-and-hinge는 후속
- 접힘 각도 슬라이더로 형상을 구동하고 현재 형상에서 바로 해석
- 스프링 무응력 기준 각도 선택 (현재 각도 / 초기 평탄)

## 단계

1. 뷰어, JSON 입력, 단위 표시 (완료)
2. 바 요소 FEM 코어, 고유치 솔버, 모드형상 표시 (완료: 밀집행렬 솔버, 자유도 1500개 한계)
3. 시간이력 해석, 지진파 CSV 입력
4. 쉘 요소, 수밀성 및 솔리드 판정
5. 힌지, 접힘 기구학, 자유도 분석
6. 복셀 변환, Abaqus `.inp` 내보내기, 검증

## Stage 3: 지진동 시간이력

- 입력 절점(`inputNodes`)과 출력 절점(`outputNodes`)은 모델 JSON에 저장되며 우클릭 메뉴로 지정한다.
- 입력 절점의 병진 3자유도에 지반가속도를 가하고, 나머지 지점은 고정이다. 영향벡터 r = -Kff⁻¹ Kfd 는 정적 해로 구한다.
- 모드중첩법: 모드별 구간선형 정확 적분(sdofPiecewise). 감쇠는 모드별 ξ 또는 Rayleigh (ξ = (α/ω + βω)/2).
- 모드 수는 목표 유효질량(기본 90%)을 모든 가진 방향에서 만족할 때까지 포함한다.
- 출력: 입력 가속도, 출력 절점 가속도(절대)·속도·변위(상대 또는 절대), 푸리에 진폭, 응답스펙트럼(Sa, Sv, Sd).
- 절대 속도/변위는 입력 가속도를 평균 제거 후 적분한 기선보정 값을 더해 얻는다.

## Stage 3.5: 쉘 요소

- 삼각형 쉘 18자유도: 면내 CST, 면외 DKT, 법선축 회전은 Hughes-Brezzi 형 벌칙(θz 와 면내 평균 회전의 차이)으로 안정화.
- DKT 중간점 회전은 모서리 접선 방향 전단 0 조건에서 수치적으로 유도했다 (공식 암기가 아님).
- 질량은 병진 consistent, 회전은 집중. 솔리드로 지정된 닫힌 패널은 강성 없이 부피×밀도 질량만 표면 절점에 분배한다.
- 검증: 캔틸레버 판 휨 0.02%, 정사각 단순지지판 1.8%, 면내 CST 캔틸레버는 약 10% 강하게 나옴(CST 한계), 메시 회전 불변, 자유판 강체모드 6개.

## Planned: Dynamics / Kinematics 작업공간 전환

- 상단 전환 탭으로 두 작업공간을 나누되 하나의 모델 상태(절점, 요소, 힌지, 경계조건)와 하나의 결과 저장소를 공유한다.
- Kinematics 결과(접힘 각도, 전개 경로의 형상)는 Dynamics 에서 해석 기준 형상으로 선택할 수 있다.
- Dynamics 결과(모드, 응답)는 Kinematics 화면에서 같은 모델 위에 겹쳐 볼 수 있다.

## Stage 4: Kinematics 작업공간 (강체 오리가미)

참고문헌: Tachi, "Simulation of Rigid Origami" (4OSME, 2009); Tachi, "Design of Infinitesimally and Finitely Flexible Origami" (2012); Imada & Tachi, "Programming sequential deployment of origami via kinematic transition fronts" (PNAS, 2026); Imada & Tachi, "Maxwell origami tube" (PRR, 2025); Imada, Hull, Ku & Tachi, "Nonlinear Kinematics of Recursive Origami Inspired by the Spidron" (Origami8).

- 변수: 회전 힌지의 접힘각 ρ (잠금 힌지로 묶인 패널은 하나의 강체).
- 구속: 패널 인접 그래프의 신장 트리 밖 힌지마다 폐합 조건 T_a·exp(ξρ)·T_b⁻¹ = I. 내부 꼭짓점 루프는 독립 식 3개, 구멍·고리 루프는 6개가 된다 (Tachi 2012).
- 야코비안: 현재 형상의 힌지 나사축(twist) 합 Σ ±ξ'_k dρ_k 로 해석적으로 계산.
- 경로: Δρ = (I − C⁺C)Δρ₀ 예측 (Δρ₀ 는 구동 힌지 + 산·골 지정 힌지), 구동 힌지를 고정한 최소노름 Gauss–Newton 보정. 수렴 실패 시 단계 이분.
- 자유도: 무한소 자유도 N − rank C, Maxwell 예측 N − 3V − 6H, 자기응력 수 = (3V + 6H) − rank C. 평면 상태는 trivial shakiness 경고.
- 각도 부호: 힌지 첫 패널의 앞면(삼각형 감김 방향) 기준 골 +, 산 −.
- 검증: 평탄접힘 4절 꼭짓점 두 분기(σ = ±1)가 Imada–Tachi Eq.1 과 1e-6 이내 일치, 미우라 3×3 은 자유도 1 · 예측 0 · 자기응력 1.
- 공유: 접힘 단계 형상을 모델 절점 좌표로 적용하면 Dynamics 해석이 그 형상으로 수행된다. 현재 Dynamics 에서는 힌지가 강접(패널 공유 절점)으로 취급된다.
