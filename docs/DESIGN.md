# 설계 결정 및 로드맵

## 기본 방침

- GitHub Pages 정적 호스팅이므로 해석 전체를 브라우저(TypeScript, Web Worker)에서 수행
- 내부 좌표계 Z-up, 단위 mm / N / tonne / s
- 입력은 Rhino/Grasshopper에서 내보낸 JSON이 주력, OBJ(선 요소)는 간이 입력
- 정밀 검증은 Abaqus `.inp` 내보내기로 로컬 교차검증 (정합성 목표 약 80%)

## 요소

- 바: 3D 보요소 6자유도, 단부 릴리스(핀/강접합), 이후 회전 스프링 확장
- 쉘: 삼각형(MITC3 계열) 우선, 사각형은 삼각형 2개로 분할, 두께는 입력값
- 집중질량: 절점 질량 및 회전관성
- 힌지: 패널 ID 쌍, 웹 UI에서 엣지 매칭 후 유형 지정 (강접 / 자유 / 회전스프링 / 비연결)

## 바 요소 규약

- 국부 x는 절점 i에서 j 방향, `orient`는 국부 z 방향의 참조 벡터 (미지정 시 전역 Z, 수직 부재는 전역 X)
- Iy는 국부 y축 둘레 휨 (국부 x-z 평면 휨), Iz는 국부 z축 둘레 휨 (국부 x-y 평면 휨)
- 단부 릴리스 `[[rx,ry,rz],[rx,ry,rz]]`: 1이면 해당 회전 해제, 정적응축 (질량은 Guyan 축소)
- 강성/질량이 전혀 없는 자유도(핀만 연결된 절점의 회전 등)는 자동 제외하고 안내
- 질량은 일관질량행렬 + 절점 집중질량, 자중은 재료 밀도로 자동 반영

## 해석

- 고유치: Free-free 및 구속 모달, 강체모드와 기구모드 구분 표시
- 응답: 모드중첩법과 Newmark-β 직접적분, 베이스 가진 (CSV: t, ax, ay, az)
- 감쇠: 모드별 감쇠비 기본, Rayleigh 선택
- 자유도 분석: 강체 자유도(구속 야코비안 영공간)와 유연 자유도(강성행렬 저에너지 모드) 별도 모듈

## 오리가미 대응

- 접힘 기구학: 강체 오리가미 우선, bar-and-hinge는 후속
- 접힘 각도 슬라이더로 형상을 구동하고 현재 형상에서 바로 해석
- 스프링 무응력 기준 각도 선택 (현재 각도 / 초기 평탄)

## 단계

1. 뷰어, JSON 입력, 단위 표시 (완료)
2. 바 요소 FEM 코어, 고유치 솔버, 모드형상 표시 (완료: 밀집행렬 솔버, 자유도 1500개 한계)
3. 시간이력 해석, 지진파 CSV 입력
4. 쉘 요소, 수밀성 및 솔리드 판정
5. 힌지, 접힘 기구학, 자유도 분석
6. 복셀 변환, Abaqus `.inp` 내보내기, 검증
